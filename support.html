USBAlias support

USBAlias watches for USB serial devices and keeps a stable name (a symbolic link) pointing at whichever /dev/cu.* path a device currently has, so scripts and tools stop chasing changing device names.

Requirements

macOS 26.5 or later. The app is a menu bar utility with no main window; open Settings from the menu bar icon (or press Cmd-,).

Common questions

Where do my aliases live?
Settings → General → Aliases shows the folder. If you have not chosen one, each rule keeps its own folder (older rules point at /tmp).
Why did my /tmp/... path stop working?
Store versions of the app are sandboxed and cannot write to /tmp, so aliases move to the folder you choose. Settings → General → Aliases can generate a small script that recreates the old /tmp paths as links to the new folder if you have scripts that still expect them.
How do I match a device reliably?
Add a rule and, in the device picker, choose the attached device; the app fills in product, manufacturer and serial number. Matching on serial number is the most precise.
Do I need to keep the app running?
Yes — it maintains the links while it runs. Turn on "Launch at Login" in Settings → General so it starts with your Mac.
Notifications or sounds are not appearing.
Check the toggles in Settings → General, and macOS System Settings → Notifications → USBAlias if you use notifications.
How do I see what the app is doing?
Settings → Log shows a live log of device connections, rule matching and link creation, with copyable text.
Does the app need network access?
Only if you opt in to anonymous diagnostics. USBAlias uses the network to send launch/running heartbeats and fingerprint-only crash records. Device names, serial numbers, USB paths, aliases and rule contents are never sent. Sharing is off until you accept it, and you can turn it off in Settings → General → Privacy.
